# ui-defensive-layout

## 设计融合：构图必须经得起真实内容

将宽度、间距和圆角映射到现有 Token，按同组关系统一节奏，不机械套用外部 680px Hero 宽度或单一间距表。嵌套圆角可用“外圆角减内边距”检查视觉贴合；极小或负值要按实际形状处理，不能产生非法半径或覆盖项目配方。

布局先用最长合理标题、空值、多语言和完整错误检查；标题均衡换行服务阅读，不靠固定换行、缩小字体或强制不换行来追求海报外观。展示用独立卡片的边界包含阴影与运动范围，圆角裁切只约束视觉层，不裁掉焦点环、菜单和真实操作。

方法参考：[Elaya AI Design Skills](https://github.com/elayadesign/ai-design-skills/tree/38bbe5765600b9178b5395a823c9f6c8d2b8e730)；以上为面向本技能的适配，现有项目契约与用户明确要求优先。

## 输入与前置检查

从仓库根读取 AGENTS.md、apps/web/AGENTS.md 和 [设计系统](../../../docs/ui/DESIGN_SYSTEM.md)，只加载本次相关规范。读取目标容器和现有断行/滚动规则；准备中英文长名、长 URL、缺图、零/多结果夹具。

## 执行

按[内容优先与参考适配](../../../docs/ui/DESIGN_SYSTEM.md#design-reference-adaptation)将视觉意图变成内容规则：图片比例／裁切方式、标题完整读取、正文阅读与局部滚动、元数据预算分别注明。目录封面、普通缩略图与中央预览沿各自 cover／contain 契约，不能为模仿图片网站改顺序、强制叠字或裁掉原图；用不同横竖比例、透明／缺图与长标题核对内容是否仍为主体。正文、代码和专业字体采用各自排版例外，不照搬外部品牌的大标题或负字距。

按内容类型选择换行/省略；原文／错误完整保留在对应阅读／详情入口，保留不等于常驻主区。图像失败在原预览尺寸内给替代状态；截图检查尺寸与横向溢出。

低频说明、长路径和诊断按设计系统的信息分层进入二级界面。错误详情弹窗限制在可用视口内并内部滚动，长堆栈、批量失败列表不撑开主区或遮住关闭／恢复操作；打开、关闭与连续错误时主区几何、预览尺寸和滚动锚点保持。不要截断唯一诊断文本来换取整洁，提供完整阅读及复制入口。

对齐时复用三槽位行：leading 不收缩，label 可换行，trailing 保留空间；多行描述不改变图标首行位置。验证无图标/无数量、1 到 1000、长无空格标识、两行说明和字体放大；检查实际容器宽度及滚动条，不给所有区域添加 gutter 或负 margin。

布局迁移测试单一顶栏搜索与长面包屑，完整路径保留 title/折叠菜单入口；集合名称与数量变化不推开 Rail 和工具栏。分别验证列表、消息与画布滚动/手势，切模块不丢草稿/选择/滚动/图视口；缩放后侧栏非模态覆盖，错误与零结果各自有真实提示。

## 动态数字与操作防挤压

按设计系统的[动态内容规则](../../../docs/ui/DESIGN_SYSTEM.md#ui-copy-interaction)使用现有数字样式／tabular-nums，覆盖时间进位、9→10／99→100、字节单位、未知总量和长计数；等宽字形仍需尾槽宽度预算。只作用于 UI 数字，不改用户内容或专业字体预览的字形特征。

对标题／时间／主控并列容器检查 min-width:0、可收缩文本列和不被挤走的操作槽。默认短按钮不换行，但长语言、放大和窄窗优先让操作组换行或用已有更多入口，不全局 nowrap 裁掉内容；完整标题仍可读取。提示和待处理文案变化不能挤动核心播放、关闭或恢复入口，不强制所有页面复制三栏播放器布局。

## 说明域与控件域

设置行按 [ui-settings-design](../ui-settings-design/SKILL.md) 的受限内容宽度和双域比例实现；其他表单复用可收缩说明列与可换行操作槽，不机械复制比例。列宽是空间预算，不是把输入框和按钮拉满的命令；长说明、未知状态或额外重置按钮出现后，先让整组上下重排，不挤走控件。设置固定导航只作用于设置，不能禁用其他模块侧栏调整。

可选 Action／Footer 槽为空时收回其边线与间距，加入内容后自然撑开；不为“以后扩展”留空白卡片。检查空槽、单控件、多控件、长文案和放大文字；Sticky 保存栏必须留出可滚动到的末尾区域，不遮校验、帮助链接或焦点。

## 菜单与树专项

左侧栏普通单行矩形控件遵守[共享等高规则](../../../docs/ui/DESIGN_SYSTEM.md#search-sidebar-consistency)：搜索、树／导航及操作行跨页使用同一密度，不因长名字／计数／pending 各自增高。长标题可省略但完整名称须从键盘可达入口读取，数量和更多操作不被挤掉。确需多行的内容采用具名例外、共享最小高度并跨页一致；正文、证据、专业预览不压进单行。文字放大时按共享规则统一增高或使用例外，不裁字、不缩小字号；菜单长描述仍可自然换行，不误套侧栏单行规则。

菜单按共享最小宽度与视口上限展开；根与子级各自计算实际槽列，不预留整组未用的图标/状态列。超长中英名称与描述允许换行，图标/状态/箭头对齐标题首行，快捷键不挤出视口。验证边缘向左避让、窄窗与三级菜单，不用业务固定定位或强行裁切解决溢出。

树样板至少覆盖深层、长中英名称、无图标、空目录、加载/失败及数量变化。复用 TreeRow 的固定槽与局部滚动，更多按钮可见性不可改变名称宽度；完整路径可读。后台目录 API 仅含文件夹时如实区分主列表文件与 UILab 文件叶子，禁止为测试伪造真实页面业务数据契约。

## 禁止事项

禁止全局 break-all、裁掉字体/证据、缩小字号硬塞或隐藏关键操作。 维护原文件、公共 API 和人工元数据边界，不自动委派开发任务。
