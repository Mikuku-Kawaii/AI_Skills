# ui-workspace-layout

## 输入与前置检查

从仓库根读取 AGENTS.md、apps/web/AGENTS.md 和 [设计系统](../../../docs/ui/DESIGN_SYSTEM.md)，只加载本次相关规范。读取 App.jsx、AppTitleBar、平台 window 适配、useSidebarLayout；检查稳定 key 和现有视角。

## 执行

新增／重组页面时按[设计意图与组件配方](../../../docs/ui/DESIGN_SYSTEM.md#design-reference-adaptation)区分阅读区、素材展示区和密集目录／工具区，列清主任务与低频操作去向。为实际分栏宽度写出保持／收缩／换行／移入已有二级入口的规则及滚动归属，再映射现有布局组件。不要把外部营销页的居中大容器、Hero 留白、定宽侧栏或移动端汉堡导航套入桌面壳；引用中的响应式推断不是本项目已验行为。

明确各区滚动所有权；复用稳定壳与语义尺寸；设置 min-width/min-height；窄窗优先收辅助区。测试布局偏好版本、异常值及持久化。

材质只改变共享表面，不给 AppShell 祖先新增 opacity/filter/backdrop-filter。权限级联使用共享 Radix Portal，验证根与子菜单包含块/定位；不要为装饰重写其授权行为。Portal 继承 html 根主题/材质，切换不改变几何、草稿、滚动、分栏偏好或图视口。正文、常驻详情及专业预览不透底。

按设计系统四层网格实施：稳定 AppShell、实际 ContentPanel 宽度驱动的内容列、leading/label/trailing 与表单槽位、语义间距。先读计算样式再迁移 NavItem/ListRow、FieldRow、PageHeader/Toolbar，保留 key、ref、事件和焦点。窄内容容器与窗口分别测试；帮助／错误按“主界面精简与反馈分层”进入二级面板／弹窗，不默认在主界面控件下插入一行。图谱世界坐标不进页面网格。

主工作区保持内容优先，只留当前任务必要操作和最少状态；低频管理、说明、诊断移到已有菜单／设置。反馈浮层使用共享 Portal，不改变主区、卡片、侧栏宽高或挤动工具栏；模态锁滚动前后补偿滚动条，保持原滚动位置与视口。不要为潜在错误预留大块空白，也不通过隐藏溢出来吞掉错误。

先审计 Rail/header/sidebar/main 的网格归属和旧标签状态。复用 NavigationContext、NavigationRail、ModuleSearch；旧集合 ID/store 和已挂载视图不删除。Rail、侧栏与主区从共享顶部内距起排，不保留独立空白标题行。左上 AppLogo、固定模块名及标题右侧的收起按钮遵循当前规范；收起后按钮仍在主区左上可聚焦。面板圆角／底部留白与顶栏细线统一消费已有 Token，不重复底部开关或用集合名称代替固定页名。模块 Toolbar 与唯一持续挂载的窗口控制共用顶部；统一预留控制槽，窄窗只让业务工具换行，检查器在工具栏下。设置统一显示当前分类标题，加载／错误也不遮挡窗口按钮；滚动后用实际点击命中和截图检查固定标题层级。拖拽只标记独立空白，不标记含交互控件的祖先；字体/素材侧栏不显示“当前集合”，原集合从资料集合管理的“打开”访问；知识继续语义分类。查询/偏好按工作区和范围隔离。窗口 API/权限读实际 Tauri 版本，onResized 监听清理；浏览器隐藏不支持按钮，实窗未测明确记录。

Rail 入口顺序、默认软件图标、底部设置/主题与空白便签遵循设计系统。底部操作与模块滚动分开；设置返回行复用 NavItem。验证便签恢复、旧集合打开、草稿/展开保留及设置内容焦点，不能删除 tab store。

## 左侧栏跨页一致性

知识、便签、设置的布局任务先读[重点页面布局](../../../docs/ui/DESIGN_SYSTEM.md#priority-page-layouts)，按三种主任务分别组织：分类／局部关系、连续编辑／阅读、分类下字段配置。先记录实际容器最小可用宽度、滚动归属及辅助区收纳条件，再复用共享壳／分栏；不把三页一律做卡片墙。知识不重复两棵完整树，便签不恢复旧标签栏或为未来聊天留空栏，设置不改表单保存语义。收起／打开前后核对视角、草稿、焦点和内容起点，具体待办按 UI-02.11～15。

左右侧栏统一使用独立 sidebar 实心面，浅深主题均比最外围 shell／chrome／Rail 浅，主工作面再浅；不以相同外壳底色抹平层级。校验真实左右栏计算色与像素，专业预览不随侧栏染色。窗口和行高仍沿原 Token，不因颜色调整改变分栏几何。

调整任何左侧栏先按[搜索与等高规则](../../../docs/ui/DESIGN_SYSTEM.md#search-sidebar-consistency)盘点 Chat／素材／字体／知识／便签／设置的搜索、树行、NavItem 和操作行。统一共享高度／密度，比较实际可见矩形及 border-box；图标、数字和更多槽居中，有无内容或状态切换不增高。长标题完整读取与多行例外按 ui-defensive-layout；不把整列、Rail 或原生热区强制成普通控件高度。搜索框在任何宿主都保留实心底色，不因侧栏背景或浮层材质透底。

## 弹层与返回路径

按设计系统的[弹层与返回规则](../../../docs/ui/DESIGN_SYSTEM.md#ui-copy-interaction)区分 Dialog、锚定菜单／Popover 和非模态侧栏；模态才限制背景滚动与焦点，普通二级菜单不改成居中模态。弹窗约束到宿主可用视口，长内容内部滚动，关闭及必要动作可达；嵌套滚动锁逐层释放，最后关闭时恢复原滚动与焦点。原生拖拽区排除输入、按钮、进度条和分栏拖柄，不导入外部固定侧栏／抽屉宽度。

验证列表→预览／详情→返回、已有标签检索→返回的范围、筛选、排序、分页／滚动锚点和选中对象；对象已删除时有有效降级锚点。复用现有状态所有者和挂载策略，不能把恢复要求理解成所有页面永久 display:none。保留状态同时暂停隐藏页面的无用播放、订阅、轮询及解码；不借鉴全局常驻播放栏改变 LOCI 的隐藏释放约定。

## 菜单与树专项

侧栏树复用 TreeRow；depth 是唯一缩进来源，祖先 padding/子行 margin 不再叠加。未知、失败、已知空与叶子分开；数量、图标文字列与更多动作保留槽位；按最新侧栏规则取消展开箭头和空展开列，行点击/方向键承接展开。容器与行内距分用 sidebar-gutter/sidebar-inset，聊天无图标仍对齐同层标题。保持分支挂载、已有 key/选中/滚动，深层在树内部滚动并保留统一背景宽度。知识大类继续来自语义结构。对照展开/收起、行悬停、尾部菜单与同级空目录。

## 禁止事项

禁止把固定知识网变成可关闭标签、拖拽区覆盖按钮、折叠时重启请求、用 body overflow:hidden 掩盖错误。 维护原文件、公共 API 和人工元数据边界，不自动委派开发任务。

## 产物与验收

布局组件与窄窗/低高/超宽截图、原生检查边界。 用户可见变化原位同步 README；待办留在 TODO，完成记录归 LOG。导航与原生降级正确；键盘分栏可用；草稿/选择/任务和视角不丢失。

验证文字/字段列起点、尾部数量变化、滚动条前后和左右侧栏调宽；用开发辅助线观察但不能改变布局。运行实际浏览器缩放测试，Windows 显示缩放另记，不能以 deviceScaleFactor 冒充。
