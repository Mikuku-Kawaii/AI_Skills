# ui-motion

## 输入与前置检查

从仓库根读取 AGENTS.md、apps/web/AGENTS.md 和 [设计系统](../../../docs/ui/DESIGN_SYSTEM.md)，只加载本次相关规范。读取 docs/ui/MOTION_SPEC.md、lib/motion 与已有动画驱动，确认是否已有同属性动画。

## 执行

消费 Token；默认 CSS；测试 system/reduce/off 和运行中系统偏好变化；图谱手势保持独立；不改变稳定 key。

借鉴其他项目时只保留必要的状态连续性，不复制其封面模糊、极光循环、大幅弹簧位移或按钮缩放。hover 渐显与键盘／触摸入口等价，状态文字、数字、焦点和命中面积不随动效跳动；控件默认按现有 MOTION_SPEC 处理，既有具名卡片例外不扩散。动画开关不触发重新解码、任务重启或实际保存，颜色与透明度数值仍沿用当前 Token。

## 禁止事项

禁止 transition-all、外围循环装饰、逐 token 动画、用动画结束事件保存或取消任务。 维护原文件、公共 API 和人工元数据边界，不自动委派开发任务。

## 产物与验收

少量真实效果、偏好持久化和模式等价测试。 用户行为变化才原位同步 README；待办留在 TODO，完成记录归 LOG。减少/关闭没有大幅运动；焦点与业务时序不变；无全图每帧 React 重渲染。

## 触发示例

- 应触发：“为侧栏和 Dialog 添加克制展开反馈”。
- 不应触发：“调整推理任务轮询间隔”。
