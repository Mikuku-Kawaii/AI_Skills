# ui-accessibility

## 设计融合：可访问的视觉完成度

高视觉标准包含键盘焦点、语义结构、文本对比与缩放后的阅读顺序；不能靠逐字显现或低透明度把正文在初始状态藏起来。网页标题与正文保留真实文本，装饰分层图不能代替可访问名称；若交付纯视频／GIF，另提供内容说明或静态替代。

以真实渲染配对检验渐变文字、磨砂和背景照片。减少动效直接呈现完整最终状态，关闭动画不改变信息和操作可达性；循环展示提供适合其使用场景的暂停／静态入口。跳转正文入口适用于有重复导航的网页，不为普通控件机械新增全站结构。

方法参考：[Elaya AI Design Skills](https://github.com/elayadesign/ai-design-skills/tree/38bbe5765600b9178b5395a823c9f6c8d2b8e730)；以上为面向本技能的适配，现有项目契约与用户明确要求优先。

## 输入与前置检查

从仓库根读取 AGENTS.md、apps/web/AGENTS.md 和 [设计系统](../../../docs/ui/DESIGN_SYSTEM.md)，只加载本次相关规范。读取触发器、Portal、嵌套弹层和快捷键；核实名称/标签/错误关联。

## 执行

复用 Radix；验证初始焦点、Tab 约束、Esc、返回触发器；输入法 composition 不触发全局操作；检查浅深色对比度和缩放。

磨砂需测渲染背景像素与文字实际 computed styles，覆盖浅/深/密线/高对比底图；文字和图标不随容器降低 opacity。验证材质关闭、缺少支持、prefers-reduced-transparency 和 forced-colors 的实心回退，以及 Portal 的主题、焦点与边界。高对比度下不得仅检查 outline 存在，还要看选中/悬停文字；尊重系统颜色。普通文字与控件识别线索分别按设计系统门槛验收，不能放宽阈值。

IconSlot 的装饰图标隐藏，图标按钮仍有独立名称；FieldRow 保持 label/control 和错误关联；ListRow 尾部操作不可嵌套按钮。确认网格重排没有改变 DOM 焦点顺序、热区和焦点可见性。辅助线必须不参与指针命中，真实浏览器缩放和文字放大均检查。

导航验收包括图标名称/aria-current、Logo 菜单方向键/Enter/Escape/焦点返回、设置路由后的内容焦点、搜索 composition/Enter 和清空。窄侧栏当前为非模态覆盖层，不能标 aria-modal 或假设焦点陷阱；先关闭嵌套菜单，再关闭侧栏。浏览器不显示原生控制，原生拖拽区不能覆盖搜索、菜单或按钮。

## 精简界面与反馈入口

执行规范的宿主配对限制：浅色外壳上的次要文字及输入边界不能直接使用工作面上的同一配方，分别复用已定主文字／主色并在共享层具名映射；不能凭色卡总体通过跳过侧栏实际相邻背景检查。颜色值仍只从设计系统和 Token 读取。

配色迁移按[冷铂灰蓝验收](../../../docs/ui/DESIGN_SYSTEM.md#platinum-gray-blue)建立真实前景／背景配对清单：正文、次文字、占位、按钮、选择、输入边界、焦点和语义状态分别检查。装饰分界不承担唯一控件识别；深色主按钮不沿用浅色白字。读取实际叠色／渲染像素，不只比较基准 HEX；状态不能只靠颜色，强制颜色仍用系统配对。媒体亮暗底图、嵌套浮层与禁用可读性不得以色卡通过替代。

被移入二级菜单的操作须可从有名称的“更多”触发器及键盘到达，不以右键或 hover 为唯一入口。短暂通知只播报一次，不抢走正在编辑的焦点；关闭后仍能从关联对象／任务入口打开错误详情。状态不能只用颜色或无名称图标表达。

阻塞弹窗有标题、简短原因与下一步，遵守既有模态焦点／逐层 Escape／回焦协议；普通失败不一律使用 alertdialog。字段错误维持 aria-invalid 和有效关联文本，提示浮层可用键盘打开；关联到隐藏详情不能代替必要的可访问说明。反复失败和批量事件合并，避免读屏重复播报及弹窗风暴。

## 名称、状态与快捷键

文案调整同步核对设计系统的[名称与状态表达](../../../docs/ui/DESIGN_SYSTEM.md#ui-copy-interaction)。可访问名称包含可见标签；显示当前模式的按钮另用状态属性和描述说明下一步，不能用另一个动作名覆盖可见文字。图标操作有独立中文名称与可发现说明，使用共享 Tooltip 或现有 title，避免双重提示；title 不替代 aria-label／aria-labelledby，也不作为键盘／触摸唯一入口。只标注实际实现且当前有效的快捷键。

键盘快捷键验证输入、textarea、contenteditable、IME 组合及弹层作用域，不能抢走空格、方向键、Enter 的原生编辑行为。hover 才显示的操作在键盘聚焦和必要触摸场景可达，隐藏后不可留下不可见焦点；危险确认初始焦点沿现有安全策略，不因主按钮强调自动聚焦删除。命中面积与图标尺寸分别按现有 Token 验收，不套外部 32px 热区覆盖桌面窗口规则。

## 按钮外观专项

减描边按[表面与轻投影](../../../docs/ui/DESIGN_SYSTEM.md#control-surface-elevation)检查：必要识别与焦点须在实际宿主成立，柔影不自动满足对比度，也不能成为唯一焦点。搜索保留实心底；投影被裁剪、同色宿主或强制颜色去影时，仍有可辨表面／必要边界与系统焦点。高对比回退允许描边，不将普通主题的少边框偏好强制到系统模式。

按设计系统“按钮外观与用途分离（2026-10-09）”分别检查 filled／ghost。透明仅是默认表面：键盘焦点、悬停、按下与持久选中必须可辨，不能只验 hover。透明按钮仍保留独立名称、完整热区及禁用语义；图标装饰与操作名称分开，危险操作不能只靠红色表达。

在实际浅深背景、图片／视频底图和强制颜色下检查识别与焦点线索；叠加按钮不能依赖碰巧较暗的测试图片或悬停才出现的底色。应用主题下禁用保留原外观类别，系统高对比允许系统表面覆盖透明偏好。切换控件使用真实 aria-pressed／aria-selected 语义，普通动作不能冒用选中态；保留菜单与分段组件既有键盘规则。

## 菜单与树专项

参考图菜单复验根/二级/三级键盘路径、指针移入子菜单时父项保持高亮、禁用项不可执行与退出回焦；权限分行的展开不得触发勾选。统一外观不改变 Radix 原语：Select 仍选值，带输入的 ObjectPopover 仍按表单 Tab。强制颜色下浮层边界和展开/选中/焦点需同时可辨，图标继承系统前景。

菜单迁移保留 Radix 键盘与焦点：ArrowRight/Left、Escape、右键和 Shift+F10、返回触发对象、菜单移交原生对话框；权限勾选与展开分别验证，侧栏不再渲染展开槽；行按钮保留 aria-expanded/controls，Enter/Space 与 Left/Right 可用。Loading 的 aria-busy 不能被 Button 覆盖，失败状态可打开详情并按原协议恢复；聊天分组右侧箭头仍由带名称的按钮控制。含输入和色块的面板用 Popover 自然 Tab，不标成 menu。高对比截图检查树选中文字是否被系统文字底板遮住，不能仅检查 computed color。

## 禁止事项

禁止可点 div 代按钮、删除焦点、模态遮罩后渲染 Select 或只靠颜色表达风险。 维护原文件、公共 API 和人工元数据边界，不自动委派开发任务。

## 产物与验收

嵌套 Select 保留最近 dialog 的 Portal 规则并兼容原生 top layer。验证实际命中与选项选择，逐层 Escape、焦点返回及根主题/材质继承，不能仅检查 DOM 存在。展开下拉使用可见视口截图，避免全页截图的视口变化触发关闭。

键盘交互测试、名称/错误关联与对比度报告。 用户可见变化原位同步 README；待办留在 TODO，完成记录归 LOG。有底与透明控件均可发现；嵌套弹层顺序正确；图谱有列表/检查器替代。
