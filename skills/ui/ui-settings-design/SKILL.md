# 设置界面设计

## 设计融合：设置不是转化页面

设置页面的主任务是准确理解和修改当前配置，不使用营销页唯一 CTA 规则隐藏独立保存、测试连接或重置操作。标题／说明／当前值／作用范围／反馈形成稳定层级；动作文案明确结果，未知配置不伪装成已启用。

排版留白、控件边界和状态样式统一到项目 Token。空操作槽不占展示面积，长说明先重排，不以外部固定宽度压缩真实控件。对焦点、编辑、保存中、失败、恢复默认和离开未保存页面逐项验证；所谓“有生命力”不能变成自动切换开关、循环保存或假进度。

方法参考：[Elaya AI Design Skills](https://github.com/elayadesign/ai-design-skills/tree/38bbe5765600b9178b5395a823c9f6c8d2b8e730)；以上为面向本技能的适配，现有项目契约与用户明确要求优先。

先让用户找到分类，再理解设置后果，最后操作控件。外观调整不改变生效时机、草稿所有权、权限或写入协议。

## 开始前

读取适用 AGENTS、目标设置组件及真实读取／提交接口，再读[设置专项规范](../../../docs/ui/DESIGN_SYSTEM.md#settings-ui-specification)。该节集中维护尺寸范围和控件矩阵；实现使用共享 Token，不在页面复制数值表。当前页面与新规范有差距时记录待迁移点，不把写完规范称为页面完成。

在现有任务计划列出受影响设置：分类、标题／说明、当前值来源、可选项、即时或保存后生效、校验、危险影响及恢复入口。只列本次范围；不另建配置引擎，也不扫描实际 Source 或调用模型来填演示数据。

## 分类与行布局

- 多设置页面使用固定宽度分类导航和受限宽度的垂直分组内容。独立页面不足五个配置项时用单栏卡片，不为视觉对称制造分类；搜索结果变少、权限暂未加载不触发重建导航。
- 设置专用导航不提供拖拽拉宽，不修改其他工作区的侧栏同步／可伸缩偏好。窄窗改成可达的分类选择或上下排布，当前分类、草稿与滚动身份保持。
- 设置行左侧为标题与说明，右侧为通用控件／动作槽；按规范比例分配可用空间，右侧对齐，垂直居中或与标题基线对齐。同组采用一致策略，校验说明不参与控件中心计算。
- 无法容纳时整行转为上说明、下控件，先保留可读性和操作入口，不缩字号硬塞。长输入、路径和多控件可以采用明确的跨行区域，不能把普通短按钮一起拉满。

## 文字与完整阅读

- 标题使用单行省略和共享中等字重，提供完整名称。Tooltip 必须键盘可达；原生 title 可以补充，不能作为唯一完整阅读方式。
- 辅助说明提炼成直接说明作用或后果的一句话；按规范限制默认行数，过长内容使用可聚焦帮助入口或 Details。说明与字段通过共享 FieldRow／aria-describedby 关联。
- 操作影响、必读风险和校验结果不能只藏在截断文本里。保留可见摘要和完整详情，链接仍可聚焦操作；不得把重要内容裁掉后只留颜色或感叹号。
- 文案分级配合 [ui-text-presentation](../ui-text-presentation/SKILL.md)，不改写用户配置值或隐藏真实失败。

## 根据状态选择控件

执行设计系统的控件矩阵：即时二元值用 Switch；少量短选项用分段／单选；多项或动态列表用 Select／Combobox；文本／数值用受限宽度 Input；密钥用可显隐的 Password Input。

先核对实际协议，再决定控件。需要点击保存的布尔草稿使用 Checkbox 等显式表单语义，不能为换成 Switch 自动提交。少量但长文字选项优先可换行 Radio Group，不压缩成难读分段；选项数量随加载变化时按列表性质选型，不因瞬时数量跳变更换控件。

优先复用当前共享原语；缺少 Switch／分段／显隐能力时先检查现有组件接口，在实施范围内补齐语义与键盘支持，不能给普通按钮加外观就冒充角色。敏感值显隐不触发保存、复制或日志记录，失败反馈不回显秘密。

## 操作、保存与危险区

- 普通行内操作用内容宽度，不随右侧网格拉伸；外观遵守设置专项的 ghost／次要描边规则，hover、焦点、禁用和 pending 都可辨。只使用实际支持的 appearance／tone，不假定存在 outline 参数。
- 有保存协议时保留表单底端或视窗右下的动作组：次要操作在左，主要保存在右。Sticky 只能依附正确滚动容器，不遮最后一项、校验或键盘焦点。
- 真正破坏性的重置、删除或注销放独立危险区，明确影响范围并使用二次确认。确认取消／Escape 不执行；保留原有更严格的维护确认，不把确认当成新增权限。普通读操作、取消草稿不套危险确认。
- 初始读取失败不以默认值覆盖已保存配置；切分类保留草稿；失败不清空输入；未知回执先核对结果，不自动重发。与 [ui-state-feedback](../ui-state-feedback/SKILL.md) 协作，不能因“即时”宣称请求发出即保存成功。

## 扩展槽

设置行必须支持右侧 Action Slot，以组合主控件、重置图标或真实状态；分组卡片必须支持可选 Footer Slot／children 供帮助和策略说明使用。先复用已有 FieldRow／Section 接口，不预造业务操作。

槽为空不渲染占位高度、分隔线或内距；有内容时自然扩展。新增动作不挤掉主控件，窄窗可换行且保持 DOM／焦点顺序；状态 Badge 必须有文字或可访问名称。插槽承载呈现，业务提交与权限留在调用方。

## 相称验收

- 检查分类找到目标、键盘顺序、标题完整阅读、长说明与链接、空槽／多动作、控件选型和保存位置。
- 覆盖窄窗、文字放大、长中英标题／路径、浅深色及高对比；危险确认与 sticky 不遮焦点，敏感值默认隐藏。
- 修改业务交互时回归切分类草稿、首载失败、无效配置、保存失败／未知回执及恢复；即时控件不重复提交，保存型控件不提前写入。沿真实协议测试，不增加无关长测。
- 只改技能时验证格式、引用和规则一致性；页面修改才执行 [ui-visual-regression](../ui-visual-regression/SKILL.md) 的相关检查。报告明确实际完成范围，不把规范目标当作现状。

## 触发示例

- 应触发：“重构设置分类与配置表单，统一开关和保存按钮”。
- 应触发：“设置项说明太长、操作按钮撑满，请调整”。
- 不应触发：“调整素材瀑布流卡片”或“修改配置文件解析算法”。
