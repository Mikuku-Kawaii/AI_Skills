# 落地页视觉系统选择

本参考提供取舍方法，不覆盖现有品牌或平台规范。

## 排版与留白

先用真实语言测试字体覆盖、回退、字重和数字，再选择正文／标题／数据角色。单一家族容易统一，两种字体也可在明确分工时使用；不要因模板偏好禁用 Inter、Roboto、Material 字体或必要的斜体。

字号与行高作为配对 Token 管理；标题可用流式尺寸并设上下限，正文保持可读。按语义断句，`text-wrap: balance`／`pretty` 只作渐进增强；窄屏不靠固定断行挤压文本。字距、行长和密度都要在真实截图上看。

沿项目间距比例建立从同组控件、卡片到章节的节奏。组内应近于组间，但不要求所有空白相同；大留白应服务阅读顺序，不能让核心操作落到不可见位置。圆角按层级和嵌套间距协调，不机械固定同一半径。

## 层级与颜色

给首要内容和主要动作明确权重，辅助信息仍可读。以背景、表面、文字、边界、强调和语义状态定义颜色角色；检验实际前景／背景组合。照片、渐变或玻璃需要文字可读的承托和实心回退，不能以“高级感”为由降低可读性。

英雄视觉应解释产品而非占位。使用有权限的产品素材、原创图形或已标明的演示，图像裁切与加载尺寸明确；字体和资源授权随素材保留。

## 动效与微交互

静态构图先成立。动效表达关联、进入、结果或必要的演示故事；不强制逐字显现、满屏菜单、每卡循环和长延迟。产品控件保持快速响应，宣传镜头可以较慢，两者分开配置。

只过渡需要的属性，优先 transform／opacity；模糊、阴影和裁切需实测，不能假定一定廉价。滚动可见性优先用 IntersectionObserver，连续滚动效果需要节流和性能证据。视口外及页面隐藏暂停不必要的循环。减少动效直接呈现信息，必要的反馈仍清楚。

## 响应式与验收

断点来自内容挤压与操作可达性；不能只把桌面稿等比缩小。核对首屏主张、CTA、插图、证据和表单在窄屏的顺序。hover 的信息与操作必须有键盘／触摸入口；骨架、spinner、局部 pending 按等待场景选用，不全局规定一种加载形式。

交付保存同条件前后图及实际观察。审美选择、可访问缺陷、业务错误和未覆盖场景分别记录，不把它们平均成一个漂亮的总分。
