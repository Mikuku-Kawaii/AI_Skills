# ui-visual-regression

## 输入与前置检查

从仓库根读取 AGENTS.md、apps/web/AGENTS.md 和 [设计系统](../../../docs/ui/DESIGN_SYSTEM.md)，只加载本次相关规范。读取 docs/ui/REFACTOR_PLAN.md、已有浏览器脚本与基线；固定数据/字体/视口，不触碰用户目录。

## 执行

外部参考驱动的 UI 任务先检查[适配与证据规则](../../../docs/ui/DESIGN_SYSTEM.md#design-reference-adaptation)：采用／拒绝理由是否落到真实组件、Token 和状态，而非只追求与品牌截图相似。对每个设计结论区分源码核对、已查看的本地截图、推断和未覆盖；参考文档里的响应式／hover 假设不能充当测试证据。将本轮组件配方逐项对应现有夹具与实际调用点，保存同数据前后图；缺少交互、异常或窄容器覆盖的范围继续留待办，不为齐全虚构数据或恢复旧页面。

运行 check:ui、前端测试、两类构建及隔离浏览器脚本；检查浅深色、动效、长内容和异常；实际打开截图，修复再复测。

材质任务先运行 test:ui:materials -- --before 保存不可覆盖基准，再实施与运行 test:ui:materials（生产加 --production）。比较相同规模图拖拽/缩放、长列表滚动、弹层打开的 rAF 采样；报告环境、数据量与局限，不把采样间隔当 FPS 保证。实际查看透明叠色、关闭材质、系统高对比度、嵌套 Portal 与中性预览截图；验证取样像素确实落在目标底图上，保留原网格/真实缩放回归。任何展示保存只拦截为内存夹具，不访问真实 API。

对齐专项先保留 alignment/before 的计算样式与前图，不覆盖基线。运行 alignment-checks 的固定 1 CSS px 同组几何检查、实际内容列检查和 browser-zoom 的隔离 tabs.setZoom 验证；记录浏览器/字体/实际视口和缩放。查看行盒与字形基线、正文起点、窄面板及滚动条截图；不能只看 pass、生成图片或放宽阈值。生产预览另测，确认辅助线与 UILab 都被移除。

布局任务先保存 test:ui:navigation -- --before，不覆盖既存前图。完成后跑开发及 --production；检验唯一搜索、Rail/header/侧栏/模块 Toolbar 几何、跨模块/集合/会话 query 隔离、首屏外匹配、迟到响应、IME、旧状态与 Logo 持久化/恢复。保留 test:ui 与 test:ui:materials 回归；实际查看前后、窄窗、正文高亮、浮层和真实缩放截图。所有 API 拦截，null 夹具保留 null，不转为空对象导致假数据崩溃。

Rail 微调使用 `node scripts/ui/verify-rail.mjs`（生产加 `--production`）。新的 before/ 单独保存，不能覆盖旧批次前图；核验底部按钮位置、默认/自定义 Logo、五入口顺序、空白便签状态恢复、设置返回项真实文字起点，以及集合管理的打开行为。

侧栏紧凑化运行 `node scripts/ui/verify-sidebar.mjs`，包括开发和生产。查看同数据、相同横向 scrollLeft 的前后图，验证无箭头行点击/方向键、错误重试、同层标题/固定缩进、聊天分组右侧箭头和无前置聊天图标。取消展开列不意味着可以放宽几何容差。

## 搜索与侧栏一致性

配色实施另外执行[冷铂灰蓝迁移验收](../../../docs/ui/DESIGN_SYSTEM.md#platinum-gray-blue)：基准表与浅深实际 Token 一致，记录别名、状态派生及全页覆盖；不可覆盖的改前图与改后图使用同数据／视口。检查普通／次要／占位文字、主按钮／选择前景、控件边界／焦点、语义状态的实际配对和像素，装饰分界不当作输入边界。覆盖按钮矩阵、Portal、磨砂／实心／强制颜色、亮暗媒体背景；比较专业内容及用户色是否保持。未测页面和原生 DPI 继续待办，不用色卡通过关闭全局迁移；未包含配色的任务仍保留当前运行主题。

按[实心搜索与左侧栏等高](../../../docs/ui/DESIGN_SYSTEM.md#search-sidebar-consistency)新增跨页同条件对照：Chat／素材／字体／知识／便签／设置的常规搜索、树／导航／操作行测量 border-box 和可见承托矩形，误差 ≤1 CSS px，不能只比较父级点击区。覆盖清空／计数／有无图标／pending／选中、窄侧栏与真实缩放；多行例外单独列明。搜索在默认／hover／focus／disabled／pending 下检查共享表面和实际空白像素，替换宿主底图不能穿透框体，前缀／清空槽无透明缺口；浅深与强制颜色都检查。文档检查不能标记这些实际页面验收通过。

## 信息精简与错误浮层专项

保留主区信息／操作迁移前后清单及二级入口，实际走通核心路径和被收纳的操作。相同视口与数据下比较正常、失败通知、详情弹窗、关闭后的主区／工具栏／卡片几何和滚动位置，错误文本变长也不造成布局位移；模态滚动锁不能引入横向跳动。

覆盖主动失败、后台批量失败、重复失败、未知写入、无内容可用、长技术详情、窄窗、键盘／IME、焦点返回和通知消失后重新查看。验证没有重复弹窗、隐形唯一恢复入口、请求重发或草稿丢失；截图要同时包含主内容和浮层。仅改 skills／规范时只报告文档检查，页面迁移与视觉验收继续留在 TODO。

## 文案与交互语义专项

用设计系统的[文案与状态规则](../../../docs/ui/DESIGN_SYSTEM.md#ui-copy-interaction)对照真实命令，不只搜索禁用词：移除关系与物理删除、清理缓存与成品、取消中与已取消、未知与失败分别走通。核对同组主要动作、切换当前值／下一动作、可见标签与可访问名称、图标说明及快捷键作用域；普通关闭不因避免“确定”而新增业务动作。

覆盖动态时间／计数进位、长中文／日文／拉丁标题、pending 标签变化、空态／无匹配／错误、模态与非模态滚动、嵌套关闭、列表／预览返回及隐藏页面资源释放。断言实际焦点、范围和布局，不把截图中的短文案或词频当行为证明。借鉴外部规范且要求不改颜色时核对 Token／CSS 差异；若有实际 UI 修改，再比原主题下各状态及原色素材，不能顺带采用参考项目的主题或阴影。

## 按钮外观专项

减少按钮／搜索描边时额外按[表面与轻投影](../../../docs/ui/DESIGN_SYSTEM.md#control-surface-elevation)保存同数据前后图和例外清单，核验共享 Button／Input／ModuleSearch 及页面覆盖。检查浅深、八状态、前缀／清空接缝、Portal、边缘裁影／真实缩放、强制颜色去影回退；必要识别与焦点按实际像素验，不凭 box-shadow 存在判通过。影晕不计入侧栏矩形高度；保留热区／几何，密集列表不逐项叠厚影。只改规范不声称样式已生效。

读取设计系统“按钮外观与用途分离（2026-10-09）”。迁移前保存实际调用点的外观、计算样式与不可覆盖前图；用同一组样例覆盖 filled／ghost × neutral／primary／danger，以及默认、悬停、按下、焦点、禁用、加载、错误反馈，选中态仅用于真实切换控件。加入纯文字、带图标、图标按钮、长文案，检查状态变化不改变几何。

样例之外复验真实提交／取消、工具栏、列表尾部、错误恢复、危险确认及图片／视频叠加按钮；浅深色、窄窗、强制颜色、真实浏览器缩放和 Portal 都需覆盖。验证同一显式外观不因切页、加入 SVG、移入弹窗或页面主题覆盖而改变；菜单／Select／分段选择不被按钮规则误伤。实际检查键盘焦点和点击，保存入口覆盖表及仍未迁移项；仅改规范时不声称组件、视觉或原生验收已通过。

## 菜单与树专项

参考图级联菜单用 `node scripts/ui/verify-cascade-reference.mjs`（生产加 `--production`），基线用 `--before` 且不可覆盖。新增样板仅在 UILab 内使用本地状态；实际入口映射见 [菜单覆盖](../../../docs/ui/MENU_COMPONENT_COVERAGE.md)。同时跑 test:ui:menus，可用 LCIW_MENU_REPORT_DIR 将本轮结果隔离到新的 data/deployments 子目录；样板截图不能替代真实字体/聊天/素材/便签菜单、Select 与 ObjectPopover 的回归证据。检查常规、展开、勾选、禁用、危险、长内容/窄窗、浅深色与高对比，几何值从设计系统对应 Token 核对。

菜单与树任务运行 test:ui:menus（开发及 --production）。before/ 只读，用同数据同状态前后截图证明箭头不再改变起点；保持 1 CSS px 门槛，检查根/子/右键菜单及 Select 的共享槽、父子字阶和交互稳定性。读 blockedInitialScans 单独记录：旧素材初始化请求在隔离路由被阻止，不是成功扫描；不得连接真实后端补测。查看高对比、material off、真实缩放截图后才能报告视觉结论。

## 禁止事项

Portal 回归必须读取选项中心的 elementFromPoint，并实际点击改值、验证 Escape 与焦点返回；computed style 正确不能证明没有被祖先裁剪。前后性能采样使用独立 rAF 生命周期，排除重复回调污染的样本，原始基准不覆盖。

禁止自动扫描实际目录/付费模型、用小图声称大数据性能、把 Web 构建当原生验收或未运行就勾选。 维护原文件、公共 API 和人工元数据边界，不自动委派开发任务。

## 产物与验收

新增颜色层级必验 shell／sidebar／background 的真实浅深画面：左右侧栏同色且比最外围浅，专业预览不参与染色。进度条同时采集确定／未知总量、原生填充与轨道、全局活动条及减少／关闭动效、强制颜色；不以 accent-color 的 computed 值替代实际条带截图。技能不复制配色值，以 DESIGN_SYSTEM 与 tokens.css 为准。

旧新覆盖表、可复现命令/截图/报告、未验证事项。 用户可见变化原位同步 README；待办留在 TODO，完成记录归 LOG。无新控制台错误/意外溢出；中央优先且辅助区可读；确认不重放；截图人工查看。
