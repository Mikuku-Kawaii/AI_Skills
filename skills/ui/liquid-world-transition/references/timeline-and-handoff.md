# 时间线、几何与状态交接

## 当前实现基线

2026-10-26 阅读 FluxManga 当前源码所得。当前调用链使用 `LiquidMetaballBar → momentumFrame` 与 `LiquidShockwaveScaffold`：表世界左切换舱 / 右导航舱，里世界左导航舱 / 右切换舱，切换时两端融入、分裂并交换布局。历史文档中的固定右侧切换键不是这一份源码的效果。

这只是来源项目基线；目标产品明确要求固定布局时保持固定。不要由一个源码例子推导所有玻璃导航必须换边。

## 两个时钟

### 底栏动量进度 t

`WorldMotion.circle` 是唯一位置 Animatable，`pod` 是它的别名，并非第二个弹簧。

| 参数 | 当前值 |
| --- | --- |
| 主动推进 | 500ms 线性推进到归一化 0.8 |
| 碰撞交接点 | 0.38，只调用一次业务切换入口 |
| 融入终点 | 0.45 |
| 分裂起点 | 0.35，与融入重叠 |
| 随后回弹 | dampingRatio 0.6，stiffness 380 |
| 回弹初速度 | 方向 × 0.8 / 0.5 秒 |

代码的阶段名为 Idle、Merging、Transfer、Splitting、Settling、Rollback。阶段判断用于表达 / 展示；不能用它替代业务提交结果。碰撞阈值是该项目视觉编排，不是平台要求，也不是等待网络的定时器。

### 页面揭示进度 p

成功提交后等待 displayReady，再用 520ms、FastOutSlowInEasing 将 p 从 0 推进到 1。两段可重叠；总耗时不是固定 1020ms，更不能把 520ms 当作业务超时。

`theme = from + (target - from) * p`，底栏语义色按该值插值，转换图标转到 theme × 180°。未提交 / 未显示就绪时保持来源主题进度。

## 共用几何

W 是底栏宽度，H 是测量后的高度，G 是间距，均转换成同一像素单位。当前主舱宽 N = W − H − G。

- merge = clamp(t / 0.45, 0, 1)。
- split = clamp((t − 0.35) / 0.65, 0, 1.13)，主舱横坐标为 (H + G) × (1 − min(split, 1))。
- 离开端中心按 merge² 向主舱运动，尺寸在 t=0.18…0.45 用平滑阶跃缩为零。
- 新端大小随 split × 1.35 增长，伴随正弦脉冲拉伸；宽 × (1 + strain)，高 ÷ (1 + strain)，保持面积近似稳定。
- 切换舱圆角为实时高度的 0.38，不机械沿用早期 24dp 固定角。
- 主舱碰撞脉冲约产生宽方向 1.5%、高方向 2.5% 的几何扰动；前景用图层缩放，外层测量尺寸保持。
- 融合颈系数为两段平滑阶跃的乘积，强度 1.8，t≤0 或 t≥1 时强制归零，避免静止时残留细桥。
- 反向通过镜像整个 frame 实现，不再为另一主题复制一套独立轨迹。
- 前景放置取整造成的偏移同步回写材质 frame。源图、SDF、描边和真实点击区域之间不得各用一组近似坐标。

当前组合中主栏与切换舱同高，高度来自内容测量并反馈到运动控制器；旋转 / 字号变化允许重新测量，不靠动画不断更改布局高度。

## 页面冲击波

切换前仍获授权的旧页绘制缩放从 1 到 0.94，旧主题底色遮蔽强度按 depart² 增加。碰撞后旧页不再参与绘制；准备阶段只有纯色。

成功且 p>0 后，径向圆孔揭示当前新页面，半径为“原点到最远角距离 + 36dp 光环宽度”乘 p，确保最终覆盖所有角。原点从窗口坐标转换为页面局部坐标，不能把屏幕坐标直接交给 Canvas。

新页轻微回弹：
`zoom = 1 + 0.04 * (exp(-6p) * cos(10p) - exp(-6) * cos(10) * p)`。
末端修正使 p=1 回到精确 1。

光环能量 sin(πp)，使用目标主题色径向渐变，约 1.2% 横纵相反缩放和 1dp 高光边；只绘制程序化图形，不对整页做动态模糊。所有缩放 / 裁剪发生在绘制层，不调整正文布局。

## 业务与生命周期

当前 FluxManga 的接入方式：

1. `requestWorldSwitch` 确认前台、稳定态、主根页、无正在进行的切换；需要时先走已有生物识别流程。
2. `performWorldSwitch` 保存当前主 Tab，再调用 begin。碰撞回调再次核对会话身份和页面条件，再调用原有业务提交。
3. `WorldSession` 是唯一提交方。目标准备成功后复制主 Tab 选择，并更新空间身份；不是共享两个空间的内容缓存。
4. resolve 忽略 Preparing；目标提交成功只标记 hasCommitted，失败则弹回实际空间。
5. `MainActivity` 等待替换页进入渲染树，重新检查前台 / 身份 / 锁定，再撤下原生保护层并调用 displayReady。当前代码使用两个帧边界；这不是跨平台通用就绪判据，也不是保证页面数据已加载完。
6. 底栏运动结束和揭示结束均满足后才结束 pending。后台 / 锁定 / 销毁时 interrupt 取消位置与揭示任务、清除回调，保留业务层已经决定的状态。

原生隐私保护、旧会话撤销、图层释放和新页面创建各有责任边界。不能为了流畅保留已撤销的旧页面截图，也不能因为减少动画而跳过身份检查。

## 源码定位与检查边界

来源项目路径前缀为 `app/src/main/java/com/flux/manga/`：

- `ui/glass/LiquidThemePalette.kt`：LiquidMomentumSpec、语义颜色、阶段。
- `ui/glass/LiquidMetaballBar.kt`：动量几何、双端轮廓、坐标修正。
- `ui/glass/WorldMotion.kt`：动画控制、一次性交接、回退及 displayReady。
- `ui/glass/LiquidShockwaveScaffold.kt`：旧页退场、新页径向裁剪与光环。
- `ui/glass/LiquidBottomBar.kt`：导航接线、主题色与转换图标。
- `MainActivity.kt`、`session/WorldSession.kt`：授权、提交和生命周期。

这些源码不随技能上传；技能描述可独立使用。旧的 `CircularRevealBox` 等辅助函数仍可能存在，不能因为函数存在就当成当前页面动画入口。当前结论来自调用链和源码，未进行本轮设备、视觉或性能验证。
