# 液态空间切换

把液态底栏与页面揭示连成一个连续过程，同时让会话层保有最终状态决定权。来源是 FluxManga 的当前实现；没有独立空间的应用可只保留主题切换，不引入不需要的鉴权或数据库层。

实现与调参读 [时间线、几何和状态交接](references/timeline-and-handoff.md)。其参数用于复现当前效果，迁移时按目标布局调整。

## 明确三种状态

- **业务状态**：当前空间、目标空间、准备 / 成功 / 失败以及会话身份，由现有业务层管理。
- **动量状态**：底栏融入、传递、分裂、回弹，共享一个运动进度和几何模型。
- **显示状态**：已提交页面是否可显示、主题揭示进度和保护层，由页面就绪条件驱动。

动画不能直接把目标空间标记为已提交，也不能靠固定延时假定鉴权、资源准备或页面就绪。底栏位移和页面揭示可以重叠，不串成必须播完的长队列。

## 接入顺序

1. 复用当前切换入口和授权流程。记录来源、目标与当前主导航项；明确哪些页面允许切换。
2. 创建一个组合生命周期持有的运动控制器，输出共享进度、形变几何、碰撞原点和揭示进度。前景和材质必须使用相同几何及坐标换算。
3. 在选定交接点只发出一次切换请求，由原有业务层准备和提交；成功后才允许显示目标页面。减少动画时立即发出同一请求，不漏掉业务动作。
4. 目标页面具备显示条件且必要保护层可以撤下后开始径向揭示。失败回到实际仍有效的空间，不展示伪造的新空间。
5. 页面切后台、锁定或控制器销毁时取消动画任务与未发出的回调，按实际业务状态收束。

## 融合与揭示

底栏轮廓由同一个 frame 提供给布局和材质：离开端缩入、另一端长出，主舱配合短促形变。当前 FluxManga 允许两端融入和分裂时间重叠；固定位置设计也可仅使用形变，但不得只改前景而遗留旧材质坐标。

页面动画作用在绘制层：旧页只在仍获授权时缩小 / 淡出；交接后绘制纯色遮蔽，成功就绪后揭示当前新页面。光环是程序化渐变，不保存旧空间截图。正文布局、字号和容器尺寸不随帧变化。

底栏颜色、切换图标旋转和页面揭示使用同一主题进度，避免新色先出现、页面仍显示旧内容。切换期间阻止重复切换与被遮住页面的误触，结束后恢复既有操作。

## 降级与适用范围

减少动画、系统动画关闭或目标项目的低效果模式，应直接呈现稳定状态并执行相同业务交接。失败和后台中断仍要处理，不能依赖动画结束事件修复状态。

独立隐私空间必须按会话释放采样层与旧结果；普通明暗主题不需要虚构这种存储隔离。当前技能不授予跨项目改动、设备测试或上传权限。

交付写清实际渲染路径、参数变化和检查范围。源码检查不等于动画观感或性能验证；遵循项目的测试安排，不因技能附带方法而自动测试、打包或扩建框架。
