# 项目初版模板与检查表

本参考文件配套 [clean-frontend-baseline](../SKILL.md) 使用，提供可直接落盘到项目根目录的 `DESIGN.md` 精简模板、平台裁剪规则、CSS Token 示例及浏览器验收核对项。

## 1. 可直接复制的 `DESIGN.md` 模板

```markdown
# 前端界面设计规范（干净初版基线）

## 1. 布局与信息降噪
- 禁止大框套小框、禁止嵌套卡片、禁止多余分割线；用对齐、间距与背景明度差区分层级。
- 禁止无意义的口号、营销副标题、冗余标签和解释性长句；界面自解释，不靠废话说明。
- 密度策略：内容展示页使用宽松留白（常规间距的 1.5 倍）；效率工具/表格/后台保持紧凑清晰，避免一屏内容过少。

## 2. 色彩系统（90/10 原则）
- 90% 面积为中性色，10% 面积仅用 1 种主强调色标注主按钮与核心状态。
- 禁止渐变色、高饱和霓虹色、毛玻璃滥用和重阴影。
- 亮色参考色阶（已有项目 Token 时以项目为准）：
  - 页面底色 `#FFFFFF` / 次级表面 `#F7F7F8` / 细边框 `#E5E7EB`（1px）
  - 主文字 `#181818` / 次要文字 `#6A6A6A` / 弱提示 `#9CA3AF`
  - 语义色仅用于状态反馈，保持低饱和克制，禁止大面积铺底。

## 3. 排版、栅格与图标
- 字体栈：`"Geist", "Inter", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`；数据/金额/时间强制使用 `font-variant-numeric: tabular-nums`。
- 字号与层级：
  - 页面主标题：`24px`（字重 600，行高 1.3）
  - 区块标题：`18px`（字重 600，行高 1.4）
  - 正文：`14px` 或 `16px`（字重 400/500，行高 1.6）；辅助信息：`12px`–`13px`
- 间距栅格：所有 margin / padding / gap 严格取 4px 整数倍，不允许任意像素。
- 圆角层级（仅用 3 档）：小控件/按钮/输入框 `8px`；容器/弹窗 `12px`–`16px`；标签/头像 `9999px`（嵌套元素满足：外圆角 ≈ 内圆角 + 内边距）。
- 图标：优先使用 Lucide（若项目指定其他图标库，先核对本地依赖导出再使用，严禁臆造图标名）；统一 `18px` 本体、`1.5px` 线宽，置于 `24×24px` 居中视觉框内。

## 4. 交互、组件与状态完整性
- 复杂浮层严禁手写几何判定：桌面端多级菜单、Popover、Dropdown、Tooltip 必须使用成熟无头组件库（如 Radix UI / Base UI / Ark UI / Floating UI `safePolygon`），确保自带开启/关闭延时、安全三角区、键盘导航与 `Esc` 关闭。
- 次要控件降噪而非彻底隐藏：列表行内次要操作平时以低对比度弱化显示，在 `hover` 或 `focus-within` 时提亮；触控设备（`@media (hover: none)`）保持可见或收拢至更多菜单。
- 状态闭环：所有可交互与数据模块必须完整处理 Hover、Active、Focus-visible、Disabled、Loading、Empty、Error。
- 动效克制：仅用于状态过渡，统一 `150ms–200ms ease-out`，尊重 `prefers-reduced-motion`，禁止弹性晃动与入场炫技动画。

## 5. 防御性布局与真实渲染验收
- 编码防溢出：按钮文字加 `whitespace-nowrap` 防误折行；Flex/Grid 文本容器必加 `min-w-0` 并做好单行截断或换行控制。
- 计算值 ≠ 渲染值：代码完成后必须通过真实浏览器打开并截图验收，重点排查文字折行溢出、图标视觉偏心、元素遮挡、窄屏/移动端错位以及 4px 栅格破坏，全部修正后再交付。
```

## 2. 按平台裁剪说明

- **桌面端 Web / Electron 工作区**：保留全部 5 节，并在桌面端菜单组件中验证鼠标斜向移动至子菜单时的悬停稳定性与键盘 `Tab` / 方向键切换。
- **纯移动端 H5 / PWA**：
  - 移除第 4 节中“桌面端多级菜单安全三角区”描述；
  - 将行内次要操作改为常驻轻量图标或底抽屉/更多菜单，不依赖 `hover` 触发；
  - 保证所有可点击控件的触控热区不小于 `44×44px`。

## 3. 基础 CSS Variables Token 示例

新项目启动时可先落盘一组基础变量，避免组件中散落硬编码色值与圆角：

```css
:root {
  --bg-page: #ffffff;
  --bg-surface: #f7f7f8;
  --border-subtle: #e5e7eb;

  --text-primary: #181818;
  --text-secondary: #6a6a6a;
  --text-muted: #9ca3af;

  --accent-primary: #2563eb; /* 按项目替换为单一主强调色 */

  --radius-control: 8px;
  --radius-surface: 12px;
  --radius-pill: 9999px;

  --font-sans: "Geist", "Inter", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
}
```

## 4. 交付前浏览器渲染验收清单

1. **文字与容器边界**：按钮、徽标与导航项无异常折行或撑破边框；长标题与长用户名在窄容器下可正常省略或安全换行。
2. **栅格与对齐**：相邻区块左右边缘对齐，所有可视留白符合 `4px` 倍数节奏，无多余套娃边框。
3. **图标与数字**：同排图标视觉大小一致且光学居中；列表金额、时间戳和统计数字列对齐不抖动。
4. **交互与键盘**：`Tab` 焦点环清晰可见；弹层/菜单可正常触发、`Esc` 关闭，桌面端多级菜单斜移不易误关。
5. **异常与边界状态**：空列表、加载中与接口报错态均有明确、克制的占位与恢复路径。
6. **宽窄视口**：桌面宽屏与移动端窄屏下均无横向滚动条、内容裁切或按钮遮挡。
