# 静态设计转动效

目标是保留原稿的构图与信息，通过可读的动作讲清视觉内容；动画请求不自动授权重新设计、发布到社交网站或修改真实业务数据。

## 明确交付场景

- 网页中的视觉：复用项目组件、Token 和实时文字，按授权只处理相应区域；默认不生成额外 MP4／GIF。
- 独立展示：明确画幅、时长、循环和所需文件；用户未指定格式时可选择通用 MP4 并说明，GIF 或平台版本按实际需要提供，不强制三份输出。
- 普通产品交互：回到该项目的产品动效规则，不能用展示节奏替代点击反馈或真实进度。

先核对来源、能分离的图层、背景、读序和输出尺寸。Figma 优先用已连接的工具及相应技能；不要求额外 PAT，也不以导出为由创建新凭据。只有扁平图时明确可重建和不可分离部分，不声称所有层可精确复原。

## 先静态，后运动

1. 保留原始参考，记录画布、字体、图层顺序、裁切和背景。静态截图与原稿对照，先修位置、遮挡、字号和缺失元素。
2. 联合的应用表面可从第一帧保持稳定，只让内容进入；独立卡片可以整体进入，但卡片、阴影、内容需共同运动。背景默认保持原稿，明确要求镜头运动时再改变。
3. 网站文字保持真实 HTML 和可访问语义；纯视频可使用授权的栅格文字层保持原稿，需给预览提供静态说明。不要把整页交互文本转成截图。
4. 绝对定位只用于固定画幅的展示舞台；响应式网站沿已有布局实现，不能整页锁定画布尺寸。

## 写清楚一个动作故事

每个需要运动的视觉先描述一件事，例如“新条目加入后列表归位”“指示器读取图表后返回”“演示提示逐字输入并呈现结果”。不要求所有图表、Logo 和按钮都循环；文字区可静止。

故事从静态基准出发并回到它。只有叙事需要的数值／文字改变；示例数据显式标为演示，与实际产品遥测隔离。兄弟视觉错开节奏，运动内容受真实圆角和边界约束，避免同时争夺注意力。产品 UI 的真实字段绝不自动打字、提交或重置。

入场、故事、归位和循环衔接分别检查；循环长度须容纳完整故事。独立视频可以循环，网站不必周期性清空所有内容。`prefers-reduced-motion` 显示最终静态画面，离屏或页面隐藏暂停，持续演示按场景提供暂停入口。

## 记录与输出

需要视频／GIF或循环精确复验时读取 [录制与导出参考](references/capture-and-export.md)。使用可控时钟固定采样，核对接缝、归位和背景；只做网页动效则无需安装编码器。

动画计时优先基于 transform／opacity，blur／clip-path 先测目标设备。避免多个时钟竞相驱动同一属性，不用动画结束事件提交业务结果。没有相应工具或素材时报告具体缺口，不声称已编码或已查看。

交付说明来源、重建差异、实际查看的关键帧、输出尺寸／时长／帧率和播放验证。PSNR 可辅助发现偏移，不能用单一分数证明视觉完全相同。
