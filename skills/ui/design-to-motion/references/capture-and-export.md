# 展示动画录制与导出

仅在需要输出媒体或精确检查循环时读取。先确认现有截图／编码工具可用，不把安装依赖或外发素材视为默认步骤。

## 可重复的时间轴

保留最终静态模式、循环预览模式与受控采样模式。受控模式关闭自行推进的 rAF，所有故事、CSS 动画和重置都由同一时间源推进；同一个时间点必须生成同一帧。字体加载与图片 decode 完成后才开始，避免把资源加载差异录进动画。

帧 i 的采样时刻使用 i / fps，区间步长用相邻时刻之差；只支持整毫秒的驱动用 `round((i+1)*1000/fps) - round(i*1000/fps)` 分配步长，避免反复累加取整导致漂移。先记录少量稳定前导帧；记录完整周期并额外覆盖一帧对应的下一周期起点，用于比较而非重复编码结尾帧。

## 四类画面检查

- 静态：相同尺寸、字体、缩放、背景和色彩设置下比较构图与文字。差分图定位问题，抗锯齿误差与结构错误分开，不追逐没有视觉影响的亚像素差异。
- 裁切：使用包含圆角、阴影及允许运动范围的遮罩，检查是否越界；不要把正常的卡片整体入场误判为故事溢出。
- 重置：检查循环末尾与起点，清空阶段是否残留 JS 驱动的数字、光点或图层；检查归位帧与静态基准是否一致。
- 实看：用空白、入场中、落定、故事中、归位、接缝帧组成接触表，并实际播放成品，查看闪烁、字体跳动、残影和节奏。图像指标通过不代替这一过程。

## 输出规格

以用户目的地和尺寸要求为准。常见通用 MP4 可用 H.264、yuv420p、偶数尺寸与 faststart；帧率、质量与时长按素材运动、设备及文件预算选择，平台上传限制使用时核查，不能把旧模板中的最大尺寸当现行限制。

GIF 用 palettegen／paletteuse 控制调色与抖动；照片注意色带，文件过大先评估帧率和颜色再降低尺寸。不强制 800×500；若用户要该画幅，先选择裁切或留边并检查内容和背景，不拉伸原稿。

导出后读取实际容器元数据，核对尺寸、编码、帧率、时长、文件大小和可解码性；再抽帧和播放。文件只保存到指定输出目录，命名清楚；生成成功与公开上传分开报告。
